## 🔧 Personnalisation

Pour modifier les couleurs, éditez les variables CSS dans `dark_hacker.css` :

```css
:root {
    --neon-cyan: #00f5ff;      /* Changez cette couleur */
    --neon-violet: #8a2be2;    /* Changez cette couleur */
    --bg-primary: #0a0a0f;     /* Changez le fond */
}
```
